MEDVIZ 3.0 — МОБИЛЬНАЯ СБОРКА ДЛЯ GITHUB

В этой папке 8 файлов, все лежат на одном уровне.
Выберите их все одновременно в окне GitHub:

1. index.html
2. styles.css
3. app.js
4. manifest.webmanifest
5. service-worker.js
6. icon-192.png
7. icon-512.png
8. README.txt

Не загружайте ZIP как единственный файл.
Сначала распакуйте архив, затем выберите все 8 файлов.

После загрузки:
GitHub → Commit changes → Settings → Pages
→ Deploy from a branch → main → /(root).

Затем откройте опубликованную ссылку в Safari:
Поделиться → На экран «Домой».

# MedWiz 3.2 QA — передача в Testing & QA

## Статус
Development завершён для вертикального сценария пилотной темы. Сборка **не Release** и не должна публиковаться как стабильная версия до прохождения QA.

## Главный сценарий
1. Открыть приложение с чистыми данными.
2. Главная → Знания.
3. Анатомия → Сердечно-сосудистая система.
4. Открыть «Камеры и клапаны сердца».
5. Проверить ContentBlocks, Source/Verification, Notes, Favorites.
6. Начать тест.
7. Сделать минимум одну ошибку.
8. На Result проверить weak items и «Разобрать ошибки».
9. Пройти повторение слабых вопросов без ошибок.
10. Проверить статус REVIEWED и закрытый Review.
11. Вернуться на Главную.

## Регрессия MedWiz 3.1
1. В 3.1 создать note, favorite, progress/review и last topic.
2. Запустить 3.2 QA.
3. Убедиться, что данные мигрировали.
4. Проверить, что `localStorage.medviz3` не перезаписан.
5. Перезапустить 3.2 QA — повторная миграция поверх v2 не должна выполняться.

## Backup
Проверить экспорт QA backup, удаление `medwizDataV2`, импорт backup и восстановление пользовательских данных.

## PWA / mobile
- iPhone Safari / Add to Home Screen.
- первый запуск online;
- повторный запуск offline;
- светлая/тёмная тема;
- отсутствие горизонтального скролла;
- нижняя навигация не перекрывает контент;
- возврат после сворачивания приложения.

## Stop criteria
Не передавать в Release при:
- потере/перезаписи данных 3.1;
- изменении stable Topic ID;
- белом экране или невозможности запуска PWA;
- ошибках, не попадающих в Review;
- backup, который не восстанавливает данные;
- расхождении медицинского текста/правильных ответов с утверждённым Medical Content.

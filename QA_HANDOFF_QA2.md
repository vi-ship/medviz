# MedWiz 3.2 QA.2 — QA HANDOFF

Статус: **QA build / NO RELEASE**. Не сливать в stable main до QA GO.

## Цель цикла
Повторная проверка Release-blockers BUG-003…BUG-007 на реальном iPhone с обязательной регрессией функций, уже прошедших QA.

## P0/P1 smoke
1. Запуск с чистым состоянием v2.
2. Запуск поверх реального `medviz3` 3.1.
3. Убедиться, что `medviz3` не изменён.
4. Открыть `Знания → Анатомия → Сердечно-сосудистая система → Камеры и клапаны сердца`.
5. Пройти 4 вопроса на 100%.
6. Перезапустить PWA и подтвердить Progress/Favorite/Note.

## BUG-003 — Review navigation
- Создать WEAK через одну ошибку.
- Открыть «Повторение» → тему.
- До ответа нажать «← К повторению» — Review должен остаться активным.
- Запустить снова, ответить на вопрос, нажать «Выйти» — сохранённый QuestionAttempt не должен исчезнуть, Review не должен ошибочно стать COMPLETED.
- Запустить снова и завершить без ошибок — Progress REVIEWED, Review COMPLETED.
- Повторить для legacy FULL_TOPIC Review после миграции 3.1.

## BUG-004 — Localization
Проверить все экраны на отсутствие технических английских labels. Особо проверить тему, Главную, Повторение, Управление, резервные копии, Экзамен.

## BUG-005 — Content presentation
- Сверить исходный медицинский текст и ответы с утверждённым эталоном: никаких редакторских изменений.
- На iPhone проверить, что блоки читаются без плотных «стен текста», нет горизонтального скролла и обрезки.
- Проверить light/dark.

## BUG-006 — Favorites & Notes
- Добавить тему в Избранное → Главная → Моя библиотека → Избранное → тема.
- Сохранить заметку → Главная → Моя библиотека → Заметки → тема.
- Проверить сохранение после перезапуска, миграции и backup/restore.

## BUG-007 — Incomplete legacy topics
После миграции 3.1 проверить `circulation` («Круги кровообращения») и другие темы без v2 ContentBlocks/Questions:
- видимый статус «Контент готовится»/«Недоступно»;
- отсутствие запуска пустого/сломанного обучения;
- отсутствие добавленного медицинского текста;
- `heart-anatomy` остаётся полностью доступной.

## Регрессия
Повторить: Migration → Review → Retest → Backup/Restore → Light/Dark → PWA offline → 100% pilot test.

## Release gate
GO возможен только после PASS реального iPhone сценария и медицинской сверки. До этого сборка остаётся QA-only.
